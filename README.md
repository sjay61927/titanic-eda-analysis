# Titanic EDA — Survival Analysis

Exploratory data analysis on the Titanic dataset to uncover 
patterns that determined passenger survival.

## Key Findings
- Women survived at 74% vs men at 19%
- 1st class passengers survived at 63% vs 3rd class at 24%
- Children under 10 had higher survival rates than adults

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn
